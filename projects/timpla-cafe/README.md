# Timpla Café

A mobile-first café website and digital menu created as Portfolio Project #1.

## Preview

Open `index.html` in a modern browser. No installation or build step is required.

For the best local-development experience, serve the folder with any static file server, for example:

```sh
npx serve .
```

## Features

- Four responsive screens: Home, Menu, Cart, and Contact
- 12-item Filipino-inspired fictional menu
- Category filtering
- Menu search
- Functional cart with quantity controls and persistent browser storage
- Reviewable and copyable demo order summary
- Responsive navigation and accessible interaction states
- Original generated hero image
- Twelve original branded product images with transparent backgrounds
- Subtle scroll reveals, product hover motion, and reduced-motion support
- No framework or build dependency

## Brand

- Name: Timpla Café
- Colors: Deep Espresso `#482B1B` and Warm Cream `#FFF7E8`
- Type: Fraunces and DM Sans
- Audience: students, Gen Z café-goers, young professionals, and adults

## Portfolio note

Timpla Café is a fictional brand. Product names, prices, contact details, and the store concept exist only for this portfolio project.

The checkout and contact form are intentionally non-transactional demonstrations. They do not submit orders, collect payments, or transmit visitor information. A real client implementation would connect these interfaces to the client's approved ordering and contact services.
