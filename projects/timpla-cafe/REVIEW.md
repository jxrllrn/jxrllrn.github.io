# Timpla Café — Project #1 Review

Reviewed against the agreed mobile-first small-business café website requirements.

## Complete

- Responsive Home, Menu, Cart, and Contact screens
- Twelve-item fictional menu with category filters
- Searchable menu
- Add-to-cart and quantity controls
- Correct subtotal, service fee, and total calculations
- Cart persistence after browser refresh
- Reviewable and copyable demo order summary
- Clear fictional-brand and non-transactional-demo disclosures
- Mobile and desktop navigation
- Keyboard focus styles, semantic headings, labels, and reduced-motion support
- Consistent brand colors, typography, tone, and imagery
- Twelve original branded product photographs integrated into the menu and cart
- Subtle, brand-appropriate motion with a reduced-motion fallback
- Basic SEO description and social-sharing metadata
- External map link for the fictional location area
- README and detailed project brief

## Intentionally simulated

- Checkout does not submit an order or collect payment.
- Contact form validates and resets fields without transmitting visitor information.
- Social accounts are identified as fictional concepts instead of linking to nonexistent profiles.

These limitations are appropriate for a fictional portfolio demonstration and should be connected only after a real client provides approved services and destinations.

## Remaining before portfolio publication

1. Create a GitHub repository and make clean, understandable commits.
2. Deploy the updated site to Vercel.
3. Test the public URL on a real phone and desktop browser.
4. Add the real deployed URL to this README.
5. Capture three screenshots: desktop hero, mobile menu, and mobile order review.
6. Record a 45–60 second walkthrough.
7. Write a short case study covering the problem, audience, process, challenges, solution, and lessons learned.
8. Add the case study and live link to the portfolio website.

## Optional client-specific additions

- Real domain
- Client-approved Messenger, WhatsApp, or ordering link
- Real contact-form service
- Real social accounts
- Exact Google Maps location
- Menu QR code
- Analytics and consent configuration

Do not add these to the fictional demo merely to make it look more complete. Add them when a real client supplies the destination accounts and approves the integration.
