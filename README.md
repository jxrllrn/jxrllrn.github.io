# Jarrell Arante — Portfolio

A responsive personal portfolio presenting Jarrell as a creative developer and designer: a first-year BSCS–AI student with experience in graphic design, video editing, publication layouts, AI-assisted workflows, and front-end website building.

## Run locally

Open `index.html` in a browser, or serve this folder with any static server.

## Included

- Responsive portfolio homepage
- Current status, focus, and honest skill-level language
- Embedded Timpla Café working prototype in `projects/timpla-cafe/`
- Project lightbox for design and video work
- Credentials and résumé links
- Keyboard-friendly interactions and reduced-motion support
- No framework or build process required

## Live project

- HINAY: https://jxrllrn.github.io/projects/hinay/ — a fictional skincare brand microsite, static campaign, and two edited Google Flow films. Brand assets and the case study are included in `projects/hinay/`. See its process notes for AI assistance and authorship.

- Timpla Café: https://timpla-cafe-six.vercel.app/
